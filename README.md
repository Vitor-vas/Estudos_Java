## 🛠️ Requirements
 
- **JDK** 17 or newer (check with `java -version`)
- **Maven** 3.9+ (or use the Maven Wrapper `./mvnw` if the project includes it)
- Any IDE: IntelliJ IDEA, VS Code, Eclipse
## 🚀 Getting Started
 
Clone the repository:
 
```bash
git clone https://github.com/<your-username>/<repo-name>.git
cd <repo-name>
```
 
Build and run a project (example with Maven):
 
```bash
cd project-one
mvn clean package
java -jar target/project-one-1.0.jar
```
 
For Spring Boot projects:
 
```bash
mvn spring-boot:run
```
 
Or open the project folder directly in your IDE and run the main class.
 
## 🧪 Running Tests
 
```bash
mvn test
```
